\# NOVA AI — LLM-Powered AI Assistant



\## About the Project



NOVA AI is a conversational AI application developed using Python, Streamlit, and the OpenAI API.



The project explores how Large Language Models (LLMs) can be integrated into real-world applications to build interactive AI assistants.



\## Objectives



\- Understand Large Language Models.

\- Integrate LLM APIs into Python applications.

\- Build an interactive AI chatbot.

\- Learn prompt-based interaction.

\- Develop practical Generative AI application skills.



\## Features



\- Conversational AI interface

\- OpenAI API integration

\- Interactive Streamlit web application

\- Environment-based API key management

\- Python backend

\## Installation



\### 1. Clone the Repository



```bash

git clone https://github.com/3407Naveen/AI-LLM.git

cd AI-LLM

```



\### 2. Create a Virtual Environment



```bash

python -m venv .venv

```



\### 3. Activate the Environment



Windows PowerShell:



```powershell

.\\.venv\\Scripts\\Activate.ps1

```



\### 4. Install Dependencies



```bash

pip install -r requirements.txt

```



\### 5. Configure API Key



Create a `.env` file in the project root:



```env

OPENAI\_API\_KEY=your\_api\_key\_here

```



Never upload your actual API key to GitHub.



\### 6. Run NOVA AI



```bash

streamlit run app.py

```
